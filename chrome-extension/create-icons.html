Extension Icon Creator

This page helps you create simple icons for the Paywall Bypasser Chrome extension.

Instructions:

  1. Right-click on each icon below
  2. Select "Save image as..." or take a screenshot
  3. Save them as icon16.png, icon32.png, icon48.png, and icon128.png in the icons/ folder
  4. Alternatively, create your own custom icons with the same dimensions

Note: You can also use any image editing software to create more professional icons.
